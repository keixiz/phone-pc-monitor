# 局域网版 · 手机监控电脑

一个程序跑在受控电脑上，手机连同一个热点 / 局域网，用浏览器打开就能看屏幕、控制键鼠。
不需要公网服务器，不需要外网（页面和依赖都在本机）。

## 三步开始

1. **同一网络**（任选一种）
   - 手机开热点，电脑连手机热点（两边都不需要外网，最省事）
   - 电脑开「移动热点」，手机连电脑（电脑本身要有网）
   - 手机和电脑本来就在同一个 Wi-Fi / 路由器

2. **电脑上启动**
   - 双击 `启动.bat`（首次会自动装依赖、生成 `config.json`）
   - 首次还要**右键 `开放防火墙.bat` → 以管理员身份运行**，放行端口（只做一次）

3. **手机上打开**
   - 看程序窗口打印的地址，或打开同目录的 `访问地址.txt`
   - 复制形如 `http://192.168.137.1:8000/?token=xxxx` 的地址到手机浏览器
   - 可「添加到主屏幕」，下次像 App 一样点开

## 文件说明

| 文件 | 作用 |
|---|---|
| `monitor-lan.py` | 一体程序：服务器 + 本机采集/控制 |
| `static/index.html` | 手机端页面（纯前端，无外部依赖） |
| `config.json` | 首次运行自动生成：端口、token、设备名、帧率、画质 |
| `访问地址.txt` | 程序启动/换网时自动更新，列出手机可用地址 |
| `启动.bat` | 启动（检查并安装依赖） |
| `启动热点并运行.bat` | 先尝试开电脑热点，再启动 |
| `开启热点.ps1` / `关闭热点.ps1` | 命令行开关 Windows 移动热点，并打印访问地址 |
| `开放防火墙.bat` | 放行入站端口（管理员，首次一次） |
| `预设配置.bat` | 生成/重置 `config.json`：预设端口、自动生成强 token 并显示手机访问地址 |
| `开机自启.bat` | 把程序加到开机启动（有 exe 指向 exe，否则用 vbs + python） |
| `后台启动.vbs` | 无窗口静默运行 |
| `开机自启.bat` / `开机自启-取消.bat` | 加入 / 取消开机自启 |
| `打包exe.bat` | 打包单文件 `dist\phone-pc-monitor.exe`（目标机不用装 Python） |

## 没有 Python / 想直接拿 exe

- **exe 版**：目标电脑不需要装 Python（exe 自带运行时）。获取方式见仓库根目录 README 的「没有 Python / 想直接拿 exe 跑」，或直接跑仓库里的 GitHub Actions「打包 Windows exe」。
- exe 是 `--onefile --noconsole`：双击静默运行，日志在 `monitor-lan.log`，地址在 `访问地址.txt`。
- 开机自启：Win+R → `shell:startup`，把 exe 快捷方式放进去。

## 热更新

- 手机控制台 → 更多 → 系统更新 → 选 Releases 下载的 zip → 上传 → 应用并重启
- 程序目录要可写；更新包会校验 sha256，页面文件可免重启生效
- 以后升级都不需要再手动拷 exe（前提是当前版本 ≥ v3.3）

## 常见问题

- **手机打不开**：先看防火墙是否放行；再确认手机和电脑在同一个热点/局域网；以 `访问地址.txt` 里的地址为准。
- **同一个 Wi-Fi 却访问不到**：路由器开了「AP 隔离 / 访客网络」时会挡住互访，换热点或在路由器关闭 AP 隔离。
- **一直「断开重连」**：电脑程序是不是没在跑；token 变了就用新地址重新打开。
- **电脑开不了移动热点**：Windows 移动热点需要电脑本身有可用网络。没有外网就反过来——手机开热点、电脑连手机。
- **画面黑**：Windows 锁屏状态下截屏就是黑的；没装 `mss` 时程序仍能启动但没画面。
- **画面卡住**：程序会自动恢复；也可以点「更多 → 重新拉画面」，或在电脑端看 `monitor-lan.log`。
- **摄像头用不了**：新版 exe 已内置摄像头组件；报「被占用」就关掉微信/QQ/相机等再试；报「没有可用摄像头」检查设备管理器。
- **换端口**：改 `config.json` 的 `port`（或用 `--port`，会写回配置）后重启，并重新运行 `开放防火墙.bat`。
- **只看到一块屏幕**：目前只采集主显示器。
- **后台启动后没反应**：看同目录 `monitor-lan.log`（无窗口运行时日志写文件）。

## 安全

- 默认只监听内网，**不要**把端口映射到公网。
- token 就是密码，别把带 token 的地址截图外发。
- 热点 / Wi-Fi 用强密码（WPA2 以上）。

## 命令行（可选）

```bash
python monitor-lan.py                 # 按 config.json 启动
python monitor-lan.py --port 8080     # 临时换端口
python monitor-lan.py --demo          # 合成画面，无屏幕环境自测
python monitor-lan.py --no-agent      # 只跑服务器，不采集本机（远程中继用）
```
